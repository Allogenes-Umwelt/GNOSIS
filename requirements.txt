# lo usa como archivo de restricciones, así que la suite prueba las mismas
# versiones que se despliegan. Antes no: la imagen instalaba de aquí con
# Flask 2.0.3 y CI instalaba versiones actuales de una lista escrita a
# mano, de modo que 511 pruebas en verde hablaban de un programa distinto
# al que corre. `pip-audit` encontraba 17 vulnerabilidades conocidas en 3
# paquetes; hoy encuentra cero, y CI lo verifica en cada push.
#
# Para subir una versión: cámbiala aquí, corre `pip-audit -r
# requirements.txt` y la suite. Un solo archivo, un solo cambio.
